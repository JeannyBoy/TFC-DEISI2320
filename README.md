Neste projeto iremos utilizar RAG (Retrieval-Augmented Generation) como ferramenta de apoio ao ensino da Literatura.

O agente será desenvolvido com base na obra Dom Casmurro, de Machado de Assis, um livro que se caracteriza, entre outros aspetos, pela complexidade da sua ironia, representando, por isso, um desafio interessante para o agente.

A ideia é verificar se esta ferramenta apresenta potencial para ser utilizada como apoio ao professor durante as suas aulas.

Um dos objetivos é avaliar se o sistema RAG consegue compreender o contexto da obra e responder a perguntas mais simples sobre o livro. Pretende-se também avaliar o potencial do RAG numa tarefa mais complexa para qualquer agente de Inteligência Artificial: a identificação de ironia. Por fim, será analisado se a utilização de RAG apresenta melhorias relativamente ao desempenho de um LLM geral nesta tarefa.
